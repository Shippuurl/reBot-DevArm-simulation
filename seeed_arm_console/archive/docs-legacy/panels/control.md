# 控制面板

控制面板是操作员入口，负责连接、使能、运行模式和故障状态。它只提交经过协议定义的命令，不直接调用 ROS 2 topic 或 Rerun API。

## 状态区

| 状态 | 含义 | 允许的操作 |
| --- | --- | --- |
| 未连接 | 未收到网关心跳 | 连接、查看本地配置 |
| 已连接/未使能 | 网关在线，驱动未进入执行态 | 请求使能、查看遥测 |
| 已使能 | 驱动可接受经过校验的运动命令 | Jog、下发轨迹、停用 |
| 故障 | 驱动或安全监督器报告故障 | 停止运动、查看原因、按流程复位 |
| 急停 | 安全回路触发 | 只能由现场安全流程恢复 |

## 连接与心跳

生产连接按钮发送 `Connect` 请求，不能仅根据 TCP 建连就显示“已连接”。网关需要返回会话 ID、协议版本、运行模式和最近一次心跳时间。当前 TCP 联调模式只用于验证数据和命令通道，正式网关必须补齐握手：

- 心跳周期 100 ms，连续 3 个周期未收到响应即标记连接异常。
- 连接异常时停止新的运动命令，保留最后一帧遥测用于诊断。
- 重连使用新的会话 ID，旧会话的轨迹句柄必须失效。

## 使能与停用

使能前检查急停释放、限位正常、驱动无故障、模式允许和速度限制有效。UI 应显示二次确认和当前安全条件；网关仍必须再次校验，不能信任 UI。

## 故障处理

故障面板至少显示故障码、来源、时间、可恢复性和建议动作。复位命令不得自动清除急停或绕过硬件安全回路。任何故障恢复都要记录到日志，并在 Rerun 时间线上留下事件。

## 设计原则

1. 危险动作使用显式确认，不用双击或隐含快捷键触发。
2. 红色表示需要停止或人工介入，黄色表示降级或等待，绿色只表示条件满足。
3. UI 卡顿不能影响控制网关的看门狗和急停路径。
