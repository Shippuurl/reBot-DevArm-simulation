# 系统架构概览

## 数据流

```text
操作员
  │ 鼠标 / 键盘 / 手柄
  ▼
Win11 egui 上位机
  │ 控制命令：连接、使能、Jog、轨迹、急停请求
  │ 状态订阅：心跳、关节、TF、诊断
  ▼
控制网关（gRPC / WebSocket）
  │ 协议校验、鉴权、限位、超时和状态机
  ▼
ROS 2 Jazzy 桥接节点（Docker）
  ├── OpenRAVE headless：规划 / IK
  ├── MuJoCo：仿真驱动（计划）
  └── 真实机械臂驱动适配器（计划）

遥测与事件 ───────────────► Rerun Logger / Viewer
```

## 关键设计决策

### 控制与可视化分离

Rerun 记录的是状态和事件，不能作为急停、使能或轨迹下发协议。控制网关必须拥有请求超时、心跳失联策略和安全状态机。

### 最新状态优先

遥测可以 200 Hz 甚至 1 kHz 发布，UI 只需要在每帧读取最新快照。后端使用有界队列或三缓冲，禁止让 UI 等待 ROS 2 网络或磁盘写入。

### 仿真与真实驱动共用协议

Mock、MuJoCo 和真实驱动都实现同一组控制/状态接口。切换运行目标时，UI 不应改变安全逻辑和数据模型。

### 先冻结协议，再实现驱动

先评审[状态机](/backend/state-machine)和[gRPC API](/backend/grpc-api)，再接入具体厂商驱动。厂商差异应限制在 adapter 层。
