# 字体许可记录

字体文件来自本地 `eguiLibrary/shadcn-rs-master/crates/shadcn-common/assets/fonts/`，上游目录说明见其 `README.md`。

| 文件 | 字体 | 上游 | 许可核对 |
| --- | --- | --- | --- |
| `Inter-*.ttf` | Inter | [fontsource/inter](https://github.com/fontsource/font-files) | 上游字体以 SIL Open Font License 1.1 发布，请随分发包保留许可和版权声明 |
| `JetBrainsMono-*.ttf` | JetBrains Mono | [JetBrains/JetBrainsMono](https://github.com/JetBrains/JetBrainsMono) | SIL Open Font License 1.1 |
| `NotoSansSC-VF.ttf` | Noto Sans CJK SC | [notofonts/noto-cjk](https://github.com/notofonts/noto-cjk) | SIL Open Font License 1.1 |

字体许可独立于 `shadcn-rs` 的 MIT/Apache-2.0 代码许可。发布二进制或公开仓库时，应同时保留各字体上游的版权和许可文本，并在上游变更后重新核对。
